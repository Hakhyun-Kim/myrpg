# MMORPG 경제 시스템 분석 — MyRPG가 배울 것

> 작성일 2026-07-31 · 대상 게임: 라그나로크 온라인, 리니지, WoW (관심작) + EVE, 알비온, 검은사막, FFXIV, 아키에이지 (경제 중심 참고작)

## 0. 요약 — 5개의 법칙

수십 년치 MMORPG 경제사에서 반복 검증된 법칙:

1. **파괴 없는 경제는 반드시 인플레이션으로 죽는다.** (RO·WoW의 실패, EVE·알비온의 성공)
2. **최고 장비가 드랍이면 제작 경제는 장식이 된다.** (WoW의 실패, 알비온의 성공)
3. **귀속(soulbound)은 인플레 방어책이지만 상호 의존을 죽인다.** (WoW BoP의 양면)
4. **거래 편의성과 거래의 '콘텐츠성'은 트레이드오프다.** (RO 노점 vs WoW 경매장)
5. **경제는 감으로 못 잡는다 — 측정하는 게임만 살아남았다.** (EVE의 상근 경제학자, 월간 통화 보고서)

MyRPG GDD v0.1은 1·2·3·5를 이미 반영하고 있다. 이 분석의 결과로 **4에서 보완할 것 하나, 그 외 조정 3건**을 §3에 제안한다.

## 1. 관심작 3종 분석

### 1.1 라그나로크 온라인 (2002, 그라비티)

**경제 구조:** 제니(단일 화폐) + 노점(개인 상점) 기반 P2P 거래. 중앙 경매장 없음(후기 서버 제외).

| 잘한 것 | 배울 점 |
|---|---|
| **노점 문화** — 프론테라 거리에 늘어선 개인 상점 자체가 소셜 공간이자 풍경이었다. 가격 비교를 위해 발품을 팔았고, 그 발품이 콘텐츠였다 | 거래를 100% 시스템화하면 이 정서가 사라진다. §3 제안 1 |
| **제련 시스템** — +7 이상 시도 시 실패하면 장비 파괴. 자발적 아이템 소멸 장치이자 도박 콘텐츠 | "업그레이드 도박 = Sink"는 검증된 공식. 단, 좌절감 관리 필요 |
| **카드 시스템** — 초저확률 드랍이 몬스터별 수집 동기 + 초고가 거래 품목을 만듦 | 희소 드랍이 시장의 '로또 층'을 형성 — 채집/사냥에 긴장감 부여 |
| 못한 것 | 교훈 |
| **Sink 부족 → 제니 인플레** — 몬스터가 무한히 제니를 뿜는데 회수 장치가 수수료 정도뿐. 수년 차 서버는 신규가 진입 불가능한 물가가 됨 | Faucet 대비 Sink 설계를 처음부터. GDD §3.2의 비율 관리가 정답 방향 |
| **오토·작업장에 무방비** — 반복 채집/사냥 구조가 봇 천국을 만들었고, 봇이 뿜는 공급이 경제를 다시 무너뜨림 | 경제 게임에서 오토는 밸런스 문제가 아니라 존망 문제 (GDD Q5 재확인) |

### 1.2 리니지 (1998, 엔씨소프트)

**경제 구조:** 아데나 + 인챈트 파괴 + 혈맹/공성 중심 수요.

| 잘한 것 | 배울 점 |
|---|---|
| **인챈트 파괴** — 무기 인챈트 실패 시 증발. 서버 최고 무기의 공급이 영원히 희소하게 유지됨. '집행검'이 수천만 원 가치를 가진 이유 | 최상위 아이템의 공급 곡선을 파괴 확률로 통제하는 가장 강력한 사례 |
| **공성전 = 수요 엔진** — 혈맹 단위 전쟁이 물약·장비·버프 소모를 대량 발생시킴. 전쟁이 곧 경기 부양 | GDD의 주간 보스가 같은 역할. "정기적 대량 소모 이벤트"는 경제의 심박이다 |
| **변신/마법인형 등 소모형 파워** — 지속시간제 파워업이 반복 구매를 강제 | 소모품 중심 설계(GDD §7.2)의 원형 |
| 못한 것 | 교훈 |
| **통제 불능의 현금 거래·작업장** — 아이템 가치가 커질수록 RMT(현금거래)와 작업장이 생태계를 장악 | 아이템 가치가 커지면 반드시 외부 경제가 침투한다. 소규모+무과금이면 유인이 작지만 방심 금지 |
| **P2W 전환** — 확률형 뽑기가 경제의 중심이 되며 플레이어 생산 경제는 소멸 | 수익 모델이 경제 설계를 잡아먹은 사례. GDD Q2에서 "판매 품목 극히 제한" 원칙 유지 |

### 1.3 월드 오브 워크래프트 (2004, 블리자드)

**경제 구조:** 골드 + 지역 통합 경매장 + 귀속(BoP/BoE) 시스템.

| 잘한 것 | 배울 점 |
|---|---|
| **경매장 UX** — 검색·입찰·즉구, 비동기 체결. 유동성 문제를 시스템으로 해결 | GDD 오더북의 원형. 소규모 서버일수록 비동기 체결이 필수 |
| **귀속 시스템** — 강한 장비를 개인 귀속시켜 '골드로 최강이 되는' 경로를 차단 | 인플레가 캐릭터 파워에 전이되는 것을 막는 방화벽 |
| **직업 전문화 (초기)** — 캐릭터당 전문 기술 2개 제한 → 상호 의존 | 마스터리 예산의 조상. 단 부캐로 우회 가능했던 게 한계 (MyRPG는 계정당 1캐릭으로 봉쇄) |
| 못한 것 | 교훈 |
| **제작 경제의 주변화** — 최고 장비는 레이드 드랍(BoP). 제작은 만렙 과정의 소모품/보조 수단으로 전락 | **"최고 아이템이 어디서 나오는가"가 경제의 전부를 결정한다.** MyRPG의 P1(모든 아이템은 플레이어가 만든다)이 반드시 지켜야 할 선 |
| **확장팩마다 리셋되는 인플레** — 골드 Faucet 증가를 새 확장팩의 가격 리셋으로 덮는 구조. 구 콘텐츠 경제는 붕괴 | 인플레를 콘텐츠 리셋으로 덮으면 세계의 연속성이 죽는다. GDD Q3(시즌제 여부) 판단 시 참고 |
| **골드 파밍·인플레** — 골드가 실물 가치를 갖자 파밍 조직이 유입, 물가 급등 | RO와 동일 교훈의 대규모 재연 |

## 2. 경제 중심 참고작 — MyRPG의 진짜 족보

### 2.1 EVE Online — 측정의 교과서
- 함선·모듈의 사실상 전부가 플레이어 생산. **전쟁으로 수조 ISK가 증발하는 순간이 곧 수요 발생**.
- CCP는 상근 경제학자를 고용하고 **월간 경제 보고서**(통화량, Sink/Faucet, 지역별 물가)를 공개.
- 교훈: **파괴 = 수요**라는 순환, 그리고 그것을 숫자로 감시하는 운영. GDD의 Sink/Faucet 대시보드(1순위 지표)는 이 계보다. 소규모여도 보고서는 자동 생성 가능 — 오히려 개발일지 콘텐츠가 된다.

### 2.2 Albion Online — MyRPG와 가장 가까운 모델
- 거의 모든 아이템이 플레이어 제작, **도시별 분리 시장**(로컬 오더북), 위험 지대 풀루트.
- 채집→정제→제작 체인이 티어제이고, 위험 지대일수록 상위 자원 — GDD §4.2·§6.1과 동형.
- 품질 등급 + 제작 특화(한 아이템을 반복 제작할수록 그 아이템만 효율 상승) → 자연스러운 전문화.
- 교훈: 이 설계가 **실제로 작동함이 증명되어 있다**는 것 자체. 단 알비온은 수만 명 규모라 유동성 문제가 없다 — MyRPG의 §9(소규모 보정)가 여전히 우리 몫의 숙제.

### 2.3 검은사막 — 가격 밴드의 선례
- 중앙 거래소의 모든 품목에 **시스템이 정한 가격 상하한 밴드**가 있고 수요에 따라 밴드가 이동.
- 밴드는 시장 조작·독점을 막지만, 가격 발견을 제한해 "진짜 시장" 느낌은 약함.
- 교훈: GDD §9.1의 NPC 밴드(60%~200% 넓은 밴드)는 검은사막보다 훨씬 느슨하게 — **바닥/천장만 제공하고 그 사이는 자유** — 가는 것이 옳다는 확신. 밴드가 좁으면 시장이 죽는다.

### 2.4 FFXIV — 제작 직업의 게임화
- 채집·제작이 전투와 동급의 '잡'이며 자체 스킬 로테이션(미니게임)이 있다.
- 교훈: 제작 행위 자체에 조작 재미를 넣으면 생활직이 "방치 클릭"이 아니라 플레이가 된다. MyRPG 제작 큐는 방치형이므로, **큐 등록 전 '공정 선택'(재료 배합·품질 vs 수량 트레이드오프) 한 겹**을 넣는 것을 검토.

### 2.5 아키에이지 — 무역과 노동력
- 무역품을 만들어 먼 도시로 운반할수록 이익 — **거리=마진**의 대표 구현. 운반 중 약탈 가능 → 위험=마진.
- 노동력(LP) 시스템: 모든 생산 행위가 계정 공용 자원을 소모 → 무한 생산 봉쇄.
- 교훈: GDD의 "도보 이동 무료/순간이동 유료 + 도시별 시장"이 같은 방향. 노동력 개념은 제작 큐(시간)가 이미 대체하고 있으므로 중복 도입 불필요.

## 3. MyRPG 반영 제안 (GDD 수정 후보)

### 제안 1 — 오더북 위에 '노점' 한 겹 (RO에서)
위탁 거래소(오더북)는 유동성의 뼈대로 유지하되, **광장에 물리적 노점을 펼 수 있게** 한다.
- 노점 = 본인 매도 주문의 공간적 진열. 체결은 오더북과 동일 엔진, 단 **노점 직접 구매 시 수수료 할인** (3% → 1%).
- 효과: 도시에 사람이 서 있는 풍경(소규모 서버에서 절실), 가격 흥정 대화 유발, RO의 정서.
- 비용: 렌더·UI 소폭. Phase 3에 배치.

### 제안 2 — 제련(강화) 도박을 Sink로 (RO+리니지에서)
GDD에 없던 요소. 장비에 +1~+7 강화를 추가하되:
- +4까지 안전, +5부터 실패 시 **강화 단계 하락 또는 (고단계) 장비 파괴**.
- 재료로 T3~T4 자원 소모 → 상위 자원의 상시 수요처 확보.
- 최상위 장비 공급을 확률로 조이는 리니지 공식의 온건판. 파괴 확률 수치는 봇 시뮬로 결정.

### 제안 3 — 제작 공정 선택 (FFXIV에서, 경량판)
큐 등록 시 세 슬라이더 중 택일: **속행**(시간 -30%, 품질 확률 하락) / **표준** / **정성**(시간 +50%, 품질 확률 상승, 재료 +10%).
- 방치 큐에 의사결정 한 겹을 넣는 최소 비용안. 명품 노리는 장인과 물량 찍는 상인이 갈라진다.

### 제안 4 — 월간 경제 보고서 자동 발행 (EVE에서)
Sink/Faucet, 품목별 물가지수, 직업 분포를 서버가 자동 집계해 **게임 내 게시판 + 개발일지 블로그에 동시 게재**. giwa-village의 "봇 주행을 콘텐츠로 승격" 아이디어와 합류. Phase 2 시뮬레이션 도구를 그대로 운영 도구로 승격하면 개발 비용이 거의 0.

### 반영하지 않는 것
- **풀루트 전면화** (EVE/알비온): 무법 지대 한정 유지. 소규모 커뮤니티에서 전면 풀루트는 이탈 가속 위험이 더 크다.
- **이중 화폐, 노동력 시스템, 가격 밴드 강제**: §2 각 항에서 기각 사유 기술.
