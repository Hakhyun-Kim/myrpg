## 키보드 이동 설계

클릭 이동(`move_to`)에 더해 방향 이동(`move_dir`)을 넣었다. 게임패드/모바일 조이스틱도 같은 메시지를 쓸 수 있다.

- **서버가 정규화한다** — 대각선이 √2배 빨라지지 않는다. 클라이언트를 믿지 않는 원칙 그대로
- **키 조합이 바뀔 때만 전송** — 매 프레임 보내면 초당 20개 레이트 리밋에 걸린다
- **맵 경계에서 축별로 미끄러진다** — 벽에 대각선으로 밀면 벽을 따라 이동
- **입력창에 포커스가 있으면 무시**, 창 포커스를 잃으면 자동 정지(키가 눌린 채 남는 문제 방지)
- 채집 예약 중 수동 이동하면 예약이 취소된다

## 검증 방법

브라우저 자동화로 실제 접속해 확인했다:
- 사이드바 패널 4개의 y좌표·높이가 순차적이고 겹치지 않음 (12/66/196/465)
- 시장 모달이 사이드바를 침범하지 않음
- 은화 500 표시, 가방 4종 정상 렌더
- 3D: `KeyD`+`KeyS` → 맵 우하단 모서리에서 정지 / `KeyW` 0.8초 → 129px 이동 (이론값 128px)
- 2D: `ArrowRight` → x축만 이동, 키를 떼면 정지
- 서버 스모크 테스트에 키보드 이동 계약 추가 (정지·대각선 정규화)
