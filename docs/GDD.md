# 프로젝트 코드네임: MyRPG — 게임 기획서 (GDD v0.2)

> 갱신 2026-07-31 / v0.1 대비: 경제 분석 반영 4건(노점·강화·공정 선택·경제 보고서) + 미결 4건 확정(영구 월드·공인 자동화·픽셀아트·유료 전제)

## 1. 한 줄 컨셉

**"혼자서는 검 한 자루도 못 만드는 세계."**
채집 → 가공 → 제작의 모든 단계를 한 캐릭터가 겸할 수 없게 강제하고, 그 결과 생기는 상호 의존을 플레이어 간 시장으로 해소하는 생활형 웹 MMORPG. 전투는 목적이 아니라 **고급 자원에 접근하기 위한 통행료**다.

그리고 이 세계의 시민은 사람만이 아니다 — **봇도 같은 문으로 들어온다** (P6, §10).

### 1.1 설계 원칙 (모든 결정의 기준)

| # | 원칙 | 의미 |
|---|---|---|
| P1 | 모든 아이템은 플레이어가 만든다 | NPC는 T1 원자재만 취급. 장비·소모품은 100% 플레이어 제작 |
| P2 | 모든 아이템은 결국 사라진다 | 내구도 소모·강화 파괴로 장비가 영구 소멸 → 제작 수요가 마르지 않음 |
| P3 | 전문화는 되돌리기 비싸다 | 마스터리 예산 제한 + 리스펙 쿨다운 → 직업 정체성 유지 |
| P4 | 오프라인에도 경제는 돈다 | 제작 큐·주문서·파견은 로그아웃 중에도 진행 |
| P5 | 인구가 적어도 시장이 멈추지 않는다 | NPC 가격 밴드 + 직업 공백 보정 + 봇 시민 (§9, §10) |
| P6 | **자동화는 시민이다** | 봇은 사람과 같은 프로토콜로 접속하는 합법 존재. **봇은 노동을, 사람은 결정을** 담당한다. 밸런스는 "모든 계정이 24시간 가동"을 전제로 잡는다 |
| P7 | 계정에는 비용이 걸린다 | 봇이 합법인 세계의 유일한 치트는 다중 계정이다. 정식 버전은 소액 buy-to-play 전제(Screeps 모델), 베타까지는 초대·수동 승인으로 계정 통제 |

## 2. 타깃·세션·프레젠테이션

- **타깃**: 전투 반복보다 "숫자가 쌓이고 시장이 움직이는 것"에 재미를 느끼는 플레이어. EVE·알비온·Screeps 경험자. **자기 캐릭터를 자동화하는 재미**를 아는 사람.
- **플랫폼**: 데스크톱 브라우저 우선 (1280x720 이상). 클라이언트는 처음부터 **Electron 래핑 가능하게** 설계 — 스팀 출시 옵션을 열어 둔다 (§14 결정 D4).
- **아트**: **픽셀아트 + CC0 에셋** (Kenney 등 탑다운 타일셋/캐릭터). 에셋은 giwa-village의 원장 패턴(출처·라이선스·체크섬을 `data/assets.json`에 기록, 테스트가 강제)으로 관리. 스타일 통일이 어긋나면 교체는 나중에 — 지금은 제작량 최소화가 우선.
- **1회 세션 목표: 20~40분**

표준 세션 루프:
```
로그인 → 제작 큐·파견 회수 (1분) → 시장 정산: 체결분 수령 + 재등록 (3분)
      → 채집/사냥 원정 또는 봇 규칙 손보기 (20분) → 원료 정제 후 큐 등록 (3분)
      → 매수 주문·노점 갱신 (2분) → 로그아웃
```
로그아웃 후에도 큐·주문·봇이 돌기 때문에 **"내일 접속할 이유"** 가 항상 걸려 있는 상태로 세션이 끝난다.

## 3. 핵심 루프

### 3.1 개인 루프 (분 단위)
```
채집 ──▶ 원료 ──▶ [가공] ──▶ 중간재 ──▶ [제작] ──▶ 완성품
  ▲                                                    │
  │                                                    ▼
  └────── 은화 ◀── 시장 판매 ◀────────────────── 사용/소모/강화 파괴
```

### 3.2 서버 경제 루프 (일/주 단위)
```
        ┌──────────────── 은화 유입 (Faucet) ────────────────┐
        │  몬스터 드랍 · NPC 원자재 매입 · 일일 납품 계약     │
        ▼
   [플레이어 간 시장] ◀──▶ [제작 체인] ◀──▶ [자원 지대]
        │
        └──────────────── 은화 소멸 (Sink) ─────────────────┐
           시장 수수료 · 장비 수리 · 강화 시도 · 창고 임대 ·
           시설 유지비 · 순간이동 요금 · 리스펙 비용          ▼
```
**목표: 주간 Sink / Faucet = 0.9 ~ 1.0.** 이 비율을 대시보드 1순위 지표로 두고, **월간 경제 보고서**(§12)로 공개한다.

## 4. 세계관과 월드 구조

### 4.1 배경
대붕괴 이후 옛 문명의 제련 기술이 소실된 대륙. 살아남은 사람들은 **상단(商團)** 을 중심으로 도시를 재건 중이다. 플레이어는 모험가가 아니라 **직인(職人)** 으로 시작한다. 왕을 죽이러 가는 서사는 없다 — 다리를 놓고, 광산을 열고, 가격을 매기는 이야기다. 골렘(봇)을 부리는 직인도 이 세계관의 일부다 — 자동화가 설정 안에 있다.

### 4.2 월드 구조 (MVP 기준 3지역 + 확장 2지역)

| 지역 | 위험도 | 자원 티어 | 특산 | 역할 |
|---|---|---|---|---|
| 초원 마을 **하란** | 안전 | T1 | 목재·구리·밀 | 시작 지역, 튜토리얼, 중앙 시장 |
| 광산 도시 **케른** | 안전 | T1~T2 | 철·석탄 | 제련·대장 시설 집중 |
| 늪지 **미르** | 위험 | T2~T3 | 약초·가죽 | 몬스터 강화, 조제·재봉 원료 |
| 화산 **칼드** *(확장)* | 위험 | T3 | 미스릴·흑철 | 고급 장비 원료 |
| 폐허 **옛수도** *(확장)* | 무법 | T4 | 유물·정수 | PvP 허용, 최고급 원료 |

- 지역 간 이동: 도보(무료, 2~4분) / 순간이동(은화 소모, 즉시) → **거리 자체가 무역 마진의 근거**
- 각 지역 시장은 **독립 오더북**. 도시 간 가격차가 무역 콘텐츠를 만든다.
- **월드는 영구다 (결정 D1).** 리셋·시즌 초기화는 하지 않는다. 내구도·강화 파괴(P2)가 상시 소프트 리셋 역할을 하고, "시즌"은 초기화가 아니라 **신규 지역·티어 개방**을 뜻한다.

### 4.3 위험도 규칙

| 위험도 | PvP | 사망 페널티 |
|---|---|---|
| 안전 | 불가 | 장비 내구도 -10%, 마을로 귀환 |
| 위험 | 합의 결투만 | 내구도 -20%, **가방 내 채집물 50% 드랍** |
| 무법 | 자유 | 가방 전량 드랍, 장착 장비 개당 25% 확률 드랍 |

> 위험도가 곧 공급량 조절 장치다. T4 자원 가격은 "무법 지대에 들어갈 각오"의 가격이다. 봇도 같은 규칙을 적용받는다 — 무법 지대에 봇을 보내는 것은 자산을 거는 결정이다.

## 5. 캐릭터와 성장

### 5.1 계정/캐릭터
- 계정당 캐릭터 **1개. 봇 도입 이후에도 불변** — 봇은 새 캐릭터가 아니라 **내 캐릭터의 자동 조종**이다 (결정 D2, §10).
- 계정 생성에는 비용 장벽(P7): 베타까지 초대·수동 승인, 정식은 소액 구매.
- 2번째 캐릭터 슬롯은 만들지 않는다. 마스터리 예산이 계정 단위 분업 강제 장치이기 때문이다.

### 5.2 마스터리 예산 — 전문화의 핵심 장치

- 스킬 10종, 각 **최대 레벨 50**
- **스킬 레벨 1당 마스터리 1포인트 소모**
- 총 예산: **시작 40 → 최대 80** (계정 업적·주요 퀘스트로 5씩 증가)

만렙 계정이 가질 수 있는 조합:

```
50 + 30       → 전문 1 + 보조 1   (스페셜리스트)
40 + 40       → 준전문 2          (밸런스형)
30 + 30 + 20  → 삼각 겸업          (자급형, 대신 전 구간 저효율)
```

**스킬 10종**

| 계열 | 스킬 | 산출물 |
|---|---|---|
| 채집 | 벌목 · 채광 · 약초학 | 원목, 광석, 생약초 |
| 가공 | 제재 · 제련 · 조제 | 판재, 주괴, 추출액 |
| 제작 | 대장 · 목공 · 재봉 · 요리 | 무기/방어구, 활/도구/가구, 로브/가방, 버프 음식 |

- 스킬 레벨 = 경험치 누적으로 오르되, 마스터리 예산을 넘겨 올릴 수 없음 (예산 부족 시 경험치는 쌓이고 레벨은 잠김)
- **리스펙**: 은화 소모(누적 투자량 비례) + **7일 쿨다운**. 되돌릴 수 있지만 가볍지 않게.

### 5.3 스킬 레벨의 효과

| 효과 | 설명 |
|---|---|
| 접근 티어 | 레벨 10/25/40에서 T2/T3/T4 해금 |
| 수율 | 레벨당 +0.5% 산출량 (50레벨 = +25%) |
| 품질 확률 | 고품질 산출 확률 (§6.3) |
| 속도 | 채집 행동 시간 감소, 제작 큐 시간 감소 (최대 -30%) |

### 5.4 전투 레벨 (별도 트랙)
- 1~30, 마스터리 예산과 **무관**. 생활직도 위험 지대에 갈 수 있어야 함.
- 상승 효과: HP, 기본 공격력, 스킬 슬롯 해금(2 → 4개)
- 전투 레벨은 **콘텐츠 게이트일 뿐 우위 수단이 아님** — 장비가 전투력의 70%를 차지하게 설계.

## 6. 자원과 제작 체인

### 6.1 티어 정의

| 티어 | 획득처 | 대략 시장가(은화) | 주 소비처 |
|---|---|---|---|
| T1 | 안전 지대, 무제한 | 1~5 | 신규 장비, 소모품 |
| T2 | 안전~위험 지대 | 10~40 | 중급 장비, 시설 자재 |
| T3 | 위험 지대, 리스폰 제한 | 80~300 | 상급 장비, 길드 시설, **강화 재료** |
| T4 | 무법 지대 + 주간 보스 | 500~3000 | 최상급 장비, 인챈트, **고단계 강화 재료** |

### 6.2 제작 체인 예시 — **강철 장검 (T3)**

```
철광석 x20 ─[제련 30]─▶ 강철 주괴 x4 ┐
                                     │
원목 x10 ──[제재 20]──▶ 손잡이재 x2 ─┼─[대장 35]─▶ 강철 장검 x1
                                     │
생가죽 x5 ─[조제 15]──▶ 무두질가죽 x1┘
```

이 하나를 혼자 만들려면 필요한 마스터리:
```
채광 30 + 제련 30 + 벌목 20 + 제재 20 + 대장 35 = 135  ≫  예산 80
```
**→ 구조적으로 불가능.** 최소 2~3명의 분업 또는 시장 구매가 강제된다. 이것이 이 게임 경제의 엔진이다.

### 6.3 품질 등급

산출물은 4등급: **조악 / 보통 / 우수 / 명품**

- 확률 = 스킬 레벨 + 재료 품질 + 시설 등급 + **공정 선택**(§6.5)의 합산
- 명품 장비에는 **제작자 이름이 각인**되어 영구히 남는다 (비용 0의 강력한 사회적 동기)
- 등급별 성능: 조악 85% / 보통 100% / 우수 115% / 명품 130% + 랜덤 옵션 1개

### 6.4 제작 큐 (오프라인 진행)

| 티어 | 1회 소요 (표준 공정) | 비고 |
|---|---|---|
| T1 | 30초 | |
| T2 | 5분 | |
| T3 | 30분 | |
| T4 | 3시간 | |

- 기본 큐 슬롯 **3개** → 창고 확장·상단 시설로 최대 6개
- 로그아웃 중에도 진행, 완료품은 서버 보관 (수령 전까지 안전)
- **큐가 이 게임의 시간 화폐다.** 슬롯 확장은 은화 Sink 중 하나.

### 6.5 공정 선택 (v0.2 신규 — FFXIV 경량판)

큐 등록 시 공정을 택일한다. 방치 큐에 의사결정 한 겹을 넣는 장치다.

| 공정 | 시간 | 품질 확률 | 재료 |
|---|---|---|---|
| **속행** | -30% | 상위 등급 확률 -50% | 기본 |
| **표준** | 기본 | 기본 | 기본 |
| **정성** | +50% | 상위 등급 확률 +50% | +10% |

명품을 노리는 장인(정성)과 물량을 찍는 상인(속행)이 같은 레시피에서 갈라진다.

## 7. 장비 — 소모와 강화 (P2의 실행)

### 7.1 내구도
- 모든 장비는 최대 내구도를 가지고, 전투/채집 시 소모
- **수리는 가능하되 최대 내구도가 회당 5% 영구 감소** → 결국 파괴
- 평균 수명: T2 장비 약 15시간 플레이, T3 약 30시간
- **이 수치는 플레이테스트에서 가장 먼저 조정될 값이다.**

### 7.2 소모품
- 요리(버프 음식): 세션당 2~3개 소모, 위험 지대 진입 시 사실상 필수
- 조제(물약): HP/자원 회복
- 소모품은 **가장 빠르게 도는 경제 품목** → 저티어 생활직의 안정 수입원

### 7.3 강화 (v0.2 신규 — RO 제련 + 리니지 인챈트의 온건판)

장비에 +1~+7 강화. 시도마다 강화 재료(T3~T4 자원 가공품) + 은화 소모.

| 단계 | 성공 시 | 실패 시 |
|---|---|---|
| +1 ~ +4 | 단계 상승 | 재료만 소실 (안전) |
| +5 ~ +6 | 단계 상승 | **강화 단계 1 하락** |
| +7 | 단계 상승 | **장비 파괴** |

- 강화 1단계당 장비 성능 +3% (최대 +21%) — 강하지만 지배적이지 않게
- 역할 셋: ① 상위 자원의 상시 수요처 ② 최상위 장비 공급을 확률로 조이는 장치 ③ 도박 콘텐츠
- **파괴·하락 확률 수치는 Phase 2 봇 시뮬레이션으로 결정한다.** 감으로 정하지 않는다.

## 9. 소규모 인구에서 경제를 굴리는 장치

> 동접 수십 명 규모에서 §8의 자유 시장은 그냥 두면 작동하지 않는다. 네 겹의 보정 + §10의 봇 시민이 함께 대응한다.

### 9.1 문제 1 — 유동성 부족 (사고 싶은데 매물이 없다)

1. **비동기 오더북**: 매수 주문을 걸어두면 접속 중이 아니어도 체결.
2. **NPC 가격 밴드**: NPC가 T1~T2 원자재에 한해 상시 매수(기준가 60%) / 매도(기준가 200%). 가격을 고정하지 않고 **바닥과 천장만** 만든다. 검은사막식 좁은 밴드는 시장을 죽인다 — 넓게 유지.
3. 기준가는 **최근 30일 플레이어 체결가의 이동평균** → 밴드가 시장을 따라간다.

### 9.2 문제 2 — 직업 공백 (아무도 제련을 안 한다)

**희소 직업 보너스**: 서버 전체에서 해당 스킬 레벨 20+ 보유자 비율이 임계치(활성 계정의 8%) 미만이면 해당 스킬 수율/경험치 최대 +30%. 게임 내 공개 표시 ("이번 주 인력 부족: 제련 +25%"). 주 1회 갱신으로 러시 방지.

봇 시대에는 이 보너스가 **봇 제작 동기**로도 작동한다 — 공백 직업은 자동화 수익률이 가장 높은 직업이다.

### 9.3 문제 3 — 신규 진입 장벽

- 시작 마스터리 40 → T1~T2 구간은 혼자서도 완결 가능
- 신규 7일간 시장 수수료 면제
- 튜토리얼의 끝은 "몬스터를 잡아라"가 아니라 **"구리 주괴 10개를 시장에 팔아라"**

### 9.4 문제 4 — 인구 급감 시 붕괴

활성 인구가 임계치 이하로 떨어지면 **NPC 대체 공급 발동**: T3까지의 중간재를 시세의 250%에 판매. 비싸서 아무도 즐겨 쓰지 않지만 서버가 죽지는 않는다. 보험 장치.

## 10. 공인 자동화 — 봇은 시민이다 (v0.2 신규, 결정 D2)

> 오토를 막는 게임이 아니라 **자동화가 게임인 게임**으로 간다. OpenMMO의 "에이전트 전용 API 없음" 사상 + Screeps의 프로그래밍 플레이 + giwa-village PROTOCOL.md 경험의 합류.

### 10.1 원칙

1. **봇 = 내 캐릭터의 자동 조종.** 계정당 캐릭터 1개는 불변. 봇 함대는 없다. 자동화는 계정을 늘리는 게 아니라 **가동 시간을 늘린다.**
2. **같은 문, 같은 규칙.** 사람 클라이언트와 봇이 **동일한 룸 계약**(Colyseus, `PROTOCOL.md`)으로 접속한다. 봇 전용 API를 만들지 않는다 — 접속 계층은 공식 SDK(colyseus.js)와 MCP 도구로 모두에게 평등하게 열려 있고, **문서의 계약 그대로 짠 봇이 실제 입장하는 스모크 테스트**가 문서-서버 일치를 강제한다. *(D7에서 재해석: 봇 제작이 AI+공식 도구 경유로 수렴한다는 전제 아래 "와이어 수준 개방"을 "공식 계층의 평등"으로 완화)*
3. **서버가 물리다.** 이동 속도, 행동 쿨다운, 채집 시간, 큐 시간은 전부 서버 권위 판정이므로 봇이라고 더 빠를 수 없다. 봇의 이득은 반응속도가 아니라 **지속 시간과 규칙성**뿐이다.
4. **밸런스 기준선 = 전 계정 24시간 가동.** 사람만 있던 시절의 "일일 접속 1시간" 가정을 버린다. 자원 리스폰·큐 시간·수율은 상시 가동 전제로 잡고, 오히려 **접속해서 직접 조작하는 행동에 보너스**를 준다 (직접 채집 수율 +25%, 직접 전투 드랍 +25% — 사람의 시간을 우대).

### 10.2 자동화의 세 층

| 층 | 대상 | 형태 |
|---|---|---|
| **파견** (게임 내, 노코드) | 모든 플레이어 | "케른 광산에 4시간 채광" 같은 큐형 명령. 제작 큐와 같은 문법 |
| **행동 규칙** (게임 내, 로우코드) | 중급 | "주괴 100개 미만이면 채광, 아니면 제련" 수준의 조건-행동 규칙표 UI |
| **오픈 계약** (외부, 코드/AI) | 개발자·AI | colyseus.js로 룸 계약에 직접 접속하는 자작 봇 + **공식 MCP 도구**(join/look/goto/gather/say — AI 에이전트는 코드 없이 플레이). LLM에게 PROTOCOL.md를 주고 봇을 짜게 하는 것이 공식 권장 플레이 (D8) |

파견·행동 규칙은 외부 봇이 하는 일의 부분집합이다 — 코딩을 못 해도 자동화의 과실을 나눠 갖게 하는 사다리이고, 셋 사이 능력 격차는 "편의성"이지 "가능/불가능"이 아니어야 한다.

### 10.3 사람의 몫

봇이 노동을 가져가면 게임의 재미는 **결정**으로 이동한다:
- 무엇을 생산할 것인가 (시세 읽기, §12 경제 보고서가 판단 재료)
- 가격을 얼마로 걸 것인가 (오더북·노점·흥정)
- 어느 위험 지대에 캐릭터를 보낼 것인가 (무법 지대 파견은 자산을 거는 도박)
- 강화를 지를 것인가 (§7.3)
- 상단 단위의 생산 계획과 계약

**플레이어의 정체성 = 일꾼이 아니라 경영자.** 이것이 v0.2에서 가장 큰 관점 전환이다.

### 10.4 남는 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 다중 계정 (봇 시대의 유일한 진짜 치트) | P7 계정 비용 + 결제 수단 단위 제한. 베타는 초대제로 수동 통제 |
| 프로토콜 남용 (초당 수천 요청) | 레이트 리밋 + 행동은 어차피 서버 쿨다운. 읽기 API도 토큰당 쿼터 |
| 코딩 격차로 인한 소외 | 파견/행동 규칙 층 + LLM 봇 빌더 가이드 제공 ("이 문서를 Claude에게 주세요") |
| 봇 버그로 인한 자산 증발 | 봇도 사망 페널티 동일 적용 — 이것은 버그가 아니라 콘텐츠다. 단, 서버 장애로 인한 손실만 복구 |

## 11. 전투 (경제의 하위 시스템으로서)

- **뷰**: 탑다운 2D (픽셀아트), 클릭 이동 + 스킬 키(1~4)
- **전투 방식**: 타겟팅 기반 + 쿨다운. 액션성보다 **자원 소모 관리**(HP/스태미나/소모품)가 핵심. 반응속도 의존을 낮게 유지하는 것은 봇-사람 공정성(§10)의 조건이기도 하다
- **몬스터 역할**: 자원 지대의 접근 통제 + 은화·가죽·정수 공급
- **파티**: 4인. 위험 지대 T3 자원 지대는 사실상 파티 필수
- **주간 지역 보스**: 8~12인 협동 (사람+봇 혼성 가능), T4 자원 대량 배출 → 주간 경제 사이클의 심장

전투 밸런스 원칙: **장비 70% / 전투 레벨 20% / 조작 10%.**

## 13. MVP 범위와 로드맵

각 단계는 **플레이 가능한 상태로 끝난다.**

### Phase 2 — 경제 (약 4주)
- 위탁 거래소(오더북), 가격 차트
- 제작 4종, 품질 등급 + 공정 선택, 장비 내구도
- 마스터리 예산 시스템

- 전투/몬스터/파티, 위험 지대
- 상단 + 공동 창고, **노점**
- **파견 시스템** (자동화 1층)

### Phase 4 — 심화
- 무법 지대 + PvP, 상단 작업장, 주간 보스
- **강화 시스템**, 희소 직업 보너스

- 월간 경제 보고서 자동 발행

**Phase 2의 봇 시뮬레이션을 건너뛰지 않는 것이 이 프로젝트의 성패를 가른다.** 봇 시뮬 인프라는 giwa-village의 merchant-bot/haggle 패턴("값은 LLM이 제안하고 하한선은 코드가 강제")을 이식해 시작한다.

| D4 | **유료 전제 + 스팀 옵션** | 베타까지 무료(초대제), 정식은 소액 buy-to-play. 스팀 출시 열어둠 (Electron 래핑 호환 설계). 다중 계정 장벽을 겸함 |
| D5 | **블록체인 미채택** | 근거 4건은 docs/research/giwa-village-review.md |
| D6 | 경제 분석 4건 채택 | 노점(§8.2)·강화(§7.3)·공정 선택(§6.5)·경제 보고서(§12.3) |
| D7 | **전송 계층 = Colyseus** *(재개봉 결정)* | 최초엔 "문서만으로 봇 작성"(P6)을 이유로 순수 JSON/WS 채택 → D8(봇 제작이 AI+공식 도구 경유로 수렴)이 전제를 바꿔 재개봉. 상태 자동 동기화·룸 수명주기 이득을 택하고 P6은 "공식 계층의 평등"으로 재해석. world.ts(게임 로직)는 네트워크 무지라 전환 비용 최소 |
| D8 | **공식 AI 도구 = MCP 서버 배포** | 봇은 전부 AI가 만든다고 가정. join/look/goto/gather/say 도구를 MCP 표준으로 배포(.mcp.json) → Claude Code 등 어떤 AI 에이전트든 이 게임의 플레이어가 됨. 전용 API가 아니라 룸 계약 위의 편의 계층 (Q7 해소) |
| D9 | **클라이언트 이원화** *(D3 부분 재개봉)* | 고비주얼 = **3D 로우폴리** (Three.js 쿼터뷰, 프로덕션 루트) / 테스트 = 2D 도형 렌더 (Phaser, /test — 가볍고 상태 검증에 유리). 두 클라이언트는 같은 룸 계약의 다른 뷰. D3의 "픽셀아트"는 3D 전환으로 재개봉 — 에셋 방향은 절차 생성 → 로우폴리 CC0(Kenney/Quaternius 계열)로 수정 |
